Signals and values

02

Connecting components

⌃
  1. Place your components.

    Arrange input, processing, and output parts in a readable layout.

  2. Connect compatible ports.

    Make sure each connection links the intended source to the intended destination.

  3. Test each stage.

    Check intermediate values before troubleshooting the entire system.

03

Troubleshooting

⌃
A component does not react

Check that the component is placed correctly, its input is connected, and the incoming value is what you expect.

The output value looks incorrect

Test the signal before and after each component. Verify encoding, bit order, and any conversion rules used by your setup.

A connection cannot be made

Check whether the selected ports are compatible and whether the game imposes placement or connection restrictions.
